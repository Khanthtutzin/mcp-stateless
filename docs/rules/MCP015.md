# MCP015 — Server declares deprecated Roots, Sampling or Logging capabilities

|  |  |
| --- | --- |
| **Severity** | `warning` |
| **Fixed by** | A change in your own server code |
| **Transports** | `stdio`, `http` |
| **Specification** | [2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/deprecated) |
| **Changelog entry** | Deprecated 1 (SEP-2577) |

## Why this changed

SEP-2577 deprecated Roots, Sampling and Logging. They still work — the
deprecation window is at least twelve months — but they are scheduled for
removal, so anything new should not adopt them, and anything existing should
plan a migration while the window is open.

```bash
npx mcp-stateless --stdio "node dist/server.js" --only MCP015
```

## Suppressing it

If this check does not apply to your server, skip it:

```bash
npx mcp-stateless --stdio "node dist/server.js" --skip MCP015
```

Rule ids are permanent and are never reissued, so a suppression cannot start
silently matching a different check later.
